OPTION B — command line (git)
----------------------------------------------------------------
First create the empty repo "RGoharimehr.github.io" on github.com, then:

  cd "personal-website"
  git init
  git add .
  git commit -m "Initial personal website"
  git branch -M main
  git remote add origin https://github.com/RGoharimehr/RGoharimehr.github.io.git
  git push -u origin main

Then on github.com open the repo > Settings > Pages, and confirm
"Source" = Deploy from a branch, Branch = main / (root). Save.
Your site: https://rgoharimehr.github.io/
